# holbertonschool-network

Introduction to computer networking: core concepts (OSI model, protocols,
addressing) and network configuration on Linux through Bash scripts.

## Projects

| Directory | Description |
|-----------|-------------|
| `basics_0/` | Networking fundamentals (OSI model, network types, MAC/IP addresses, TCP/UDP, ports) and diagnostic scripts: listing listening ports and checking host reachability with `ping`. |
| `basics_1/` | Network configuration: editing `/etc/hosts`, displaying active IPv4 addresses, and listening on a local port. |

## Requirements

- Ubuntu / Linux
- Networking tools: `netstat`, `ping`, `ifconfig`, `nc`

All Bash scripts:

- start with `#!/usr/bin/env bash`;
- must be executable (`chmod u+x file`);
- pass `shellcheck` without errors.
